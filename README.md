## Tech stack

Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, Yellowbrick, ucimlrepo

## Run locally

```bash
git clone https://github.com/amitmohanty022/ML-Algorithm-Projects.git
cd ML-Algorithm-Projects
pip install jupyter pandas numpy scikit-learn matplotlib seaborn yellowbrick ucimlrepo
jupyter notebook
```
